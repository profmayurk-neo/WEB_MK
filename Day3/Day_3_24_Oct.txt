# 1. The <script> Tag

* <script>: An HTML tag used to embed or reference executable client-side JavaScript code within a webpage.

# 2. The Curly Braces { } (Block Scope)

* { ... }: Defines a block in JavaScript.
* A block groups multiple statements together. 
It creates a local boundary known as block scope for variables declared with modern keywords like let and const.

# 3. Variable Declarations

* let userName;:
* let: A keyword used to declare a block-scoped variable.
   * userName: The identifier (name) of the variable. Because it is inside the { } block, 
it only exists inside that block. Trying to access it outside will throw a ReferenceError.
* var userAge;:
* var: An older keyword used to declare a variable.
   * userAge: The identifier (name) of the variable. Unlike let, var ignores block scope. It is either globally scoped or function-scoped. Because it is not inside a function here, it leaks out of the { } block and is available globally.

## 4. Code Comments

* //console.log(userName);: The // symbols denote a single-line comment. The JavaScript engine completely ignores this line. If you were to uncomment it (remove the //), the program would crash with a ReferenceError because userName is not defined outside the block.

## The Output Statement

* console.log(userAge);:
* console: A built-in global object that provides access to the browser's debugging console.
   * .log(): A method (function) belonging to the console object that prints messages or variables to the console screen.
   * Output: This line will successfully print undefined to your console. It prints undefined because var userAge was declared but never assigned a value (like userAge = 25;).

Feature	var keyword	let keyword

Scope	Function/Global Scoped. It ignores blocks { } and leaks into the outer scope.	Block Scoped. It is strictly bound within the nearest curly braces { }.
Hoisting Behavior	Hoisted and initialized as undefined. You can access it before its declaration line without crashing.	Hoisted but not initialized. It sits in a "Temporal Dead Zone" (TDZ). Accessing it early crashes the script.


Why your snippet fails:

1. The JavaScript engine reads the file.
2. It sees var userName; twice and says, "That's fine."
3. It sees let userAge; twice and immediately halts execution, throwing an error because you cannot declare the same let variable twice in the same scope.
4. Because of this syntax error, console.log(userName); never even runs.
